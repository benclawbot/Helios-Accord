# Helios Accord

A playable single-system grand-strategy game about shaping humanity's interplanetary future.

## Run

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite.

## Gameplay

- Manage five distinct colonies and their monthly economies.
- Specialize worlds and construct modular buildings.
- Balance resources, population growth, factions, laws, and fleets.
- Research technologies across physics, society, and engineering.
- Explore a 56-technology long-term research catalog.
- Generate trade points on trade worlds and purchase resources through the marketplace.
- Colonize Mercury, Venus, Jupiter, Saturn, Uranus, Neptune, and Pluto.
- Respond to recurring political, technological, economic, exploration, and first-contact events.
- Advance through decades until the Silent Geometry appears.
- Decide humanity's fate through a multi-stage, three-ending event chain.

Use the pause and speed controls in the top-right corner. Saves are stored in the browser's local storage.
